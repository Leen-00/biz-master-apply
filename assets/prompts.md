# 各环节 Prompt 模板

> 用法：把对应小节的 Prompt 复制给 AI，`【】`内替换为真实信息。本 Skill 激活后，AI 已读取固定背景，可省略重复介绍。

## 1. 选校定位

### 1.1 背景诊断与冲稳保初筛
```
基于我的固定背景，先做一次申请竞争力诊断：
1. 列出我的优势、短板、硬门槛风险（语言小分、先修课、本科背景、跨专业）；
2. 按【英国/港/新/爱/澳】分别给出冲刺、匹配、保底三档院校与商科项目建议，每档 3-5 个；
3. 每个项目标注：我可能匹配的理由、主要风险、需要进一步核实的官网要求；
4. 明确哪些结论是推测，需要我去官网核对。
不要给"保录"承诺，不要编造录取数据。
```

### 1.2 官网要求提取（粘贴招生页原文）
```
下面是某项目官网招生页的原文。请只从这段文字里提取，不要补充外部信息：
- 学位/本科背景要求
- 先修课要求（数学、统计、会计、编程等）
- 最低 GPA / 均分要求
- 语言成绩与小分要求、是否接受雅思/托福
- 是否要求 GRE/GMAT、工作经验
- 申请开放与截止日期（轮次、是否滚动录取）
- 学费、学制
- 其他硬性材料要求
提取后用表格列出；原文没写的项目标"官网未说明"。

【粘贴招生页原文】
```

### 1.3 同背景案例比对
```
我把几个录取/被拒案例贴给你。请对照我的背景，分析：
1. 每个案例录取者的核心优势是什么，哪些是我也具备的、哪些是我缺的；
2. 被拒案例可能的原因；
3. 据此判断我对【某项目】属于冲/稳/保的哪一档，并说明依据的薄弱处。

【粘贴案例】
```

### 1.4 跨专业 / 先修课缺口分析
```
我是【财管】背景，想申【商业分析/金融】。请对比目标项目常见先修课要求，
列出：我已经覆盖的课程、缺口课程、可以用什么方式弥补（补修网课、自学作品、先修课证明），
以及哪些项目对跨专业更友好、哪些门槛较硬。
```

## 2. 文书（PS / SOP）

### 2.1 第一步：素材脑暴（自己先写，不用 AI 成文）
> 新建文档，随手写混乱要点：做过的项目、为什么想申这个方向、最有成就感/挫败的一件事、目标项目最吸引你的点、职业规划。语法不管，先把事实倒出来。

### 2.2 第二步：AI 搭结构（不写正文）
```
这是我关于学术背景、实习经历和申请目标的原始笔记。我要申【某大学 某硕士项目】。
不要替我写成文章，只做两件事：
1. 给出一个逻辑清晰的 5 段式 PS 大纲；
2. 逐段说明：这段要放什么信息、要论证什么、用我哪段经历支撑。
要求：叙事围绕"我为什么适合这个项目"，避免空泛套话。

【粘贴原始笔记】
```

### 2.3 第三步：自写初稿后润色（锁死语气和用词）
```
请审阅我这段 PS 初稿：
- 修正语法错误、改善语句流畅度；
- 不要改动我的核心用词，不要把语气改得过于正式；
- 保留我原本的语气，表达直接、利落、学术化；
- 指出哪些句子显得空泛/像模板，以及可以补什么具体细节；
- 不要新增我没有提供的经历、数字或成果。

【粘贴初稿段落】
```

### 2.4 文书自检 / 评估
```
请以招生官视角审阅这篇 PS，按以下维度打分（1-5）并给修改建议：
动机与项目匹配度、经历支撑、逻辑结构、个人细节是否具体、语言表达、有无 AI 模板腔。
列出最需要改的 3 个问题和对应改法。
注意：挑出 "delve / tapestry / testament / fostering" 这类常见 AI 套话词并替换。

【粘贴全文】
```

### 2.5 项目定制化（每所学校一版）
```
我要把 PS 适配【某大学 某项目】。请结合该项目的课程设置、方向特色、师资或资源，
帮我找出我经历与该项目的契合点，列出需要在文书里点明的 3-5 个具体匹配点；
哪些通用表述必须改成针对这个项目的内容。不要编造该校教授或课程名，我会自己核对。
```

### 2.6 研究经历段落（SOP / 研究型短文）
```
这是我的一段科研/课程项目经历。请帮我组织成 SOP 里的研究经历段落：
讲清背景问题、我用的方法/工具、我的具体贡献、结果与反思；用学术但直白的英文表达，
突出量化结果。事实以我给的为准，不补数据。

【粘贴经历素材】
```

## 3. CV / 简历

### 3.1 经历改写为专业 CV 条目
```
我用大白话讲一段实习/项目，请你把它改成 3 条强 CV 要点：
- 每条以强动作动词开头；
- 保留我提到的技术工具；
- 突出最终结果（尽量量化，没有数字就写可验证的产出）；
- 英文，简洁，符合学术/申请 CV 风格。

我的原始描述：【粘贴，例如：我用 Python 分析销售数据，搭了预测模型，预测准确度提升 15%，主管比较满意】
```

### 3.2 CV 整体对齐项目要求
```
下面是我的现有 CV 和某项目的申请要求。请逐条分析：
1. 哪些内容与项目要求匹配，哪些不匹配；
2. 哪些经历该强化、哪些该删减或重组；
3. 给出可执行的修改建议（改写、补充、删除、调整顺序），每条说明理由；
4. 检查是否有 ATS 筛选系统不友好的排版/表述问题。

【粘贴 CV】
【粘贴项目要求】
```

## 4. 推荐信

### 4.1 给推荐人的沟通要点提纲
```
我要请【某实习领导/课程老师】为我写申硕推荐信。请帮我整理一份给推荐人的沟通材料：
- 我与这位推荐人的关系、共事时长与场景；
- 想让信中突出我的 2-3 个品质；
- 支撑这些品质的具体事例（来自我的经历，需我确认真实发生）；
- 我的申请方向与职业目标，方便推荐信谈"契合度"。
提醒：推荐信不能虚构与推荐人没有互动过的经历。
```

### 4.2 推荐信英文草稿框架（供推荐人参考/修改）
```
基于上面的要点，写一封英文推荐信草稿框架：
- 开头说明推荐人身份、与我的关系、了解程度；
- 正文 2-3 段，每段围绕一个品质 + 一个具体事例；
- 结尾给出对比定位与推荐力度；
- 语气像真人写的，克制、具体，不要夸张奉承；
- 所有事实标注"需推荐人核实"，不得虚构。
```

### 4.3 推荐信去 AI 味 / 真实性检查
```
请检查这封推荐信草稿：哪些表述太套话、太笼统、像 AI 生成；
哪些地方缺少可验证的具体事例；给出改得更像真人评价的建议。不要替我虚构事例。

【粘贴草稿】
```

## 5. 面试与邮件

### 5.1 AI 模拟面试官（一问一答 + 点评）
```
你是【一所欧洲/港新商科强校】的招生面试老师，我是申请【某硕士】的学生。
请围绕我的实习、项目、申请动机问我 5 个有难度的问题，一次只问一个；
我回答后，你先严格点评我的回答（逻辑、细节、专业度、是否有漏洞），再问下一个。
不要放水。
```

### 5.2 常见问题准备
```
针对商科硕士面试，列出我这个背景最可能被问到的：
1. 行为类问题（为什么选这个项目、职业规划、团队合作、遇到的困难）；
2. 专业/量化类问题（会计、金融、统计、SQL/Python 基础）；
3. 针对我简历每段经历可能追问的细节。
每题给一个回答思路框架和我需要提前准备的素材。
```

### 5.3 套磁 / 咨询邮件
```
写一封 150 词左右的英文邮件给【某人/招生官】，目的是【套磁/询问项目问题/补充材料】：
- 主题行直接写清身份、时间、研究方向；
- 正文简短、直接、专业，不要客套吹捧；
- 点明我读过/了解的具体内容和我的相关经历；
- 结尾写清期待回复的事项。
不要虚构教授论文或我的成果。

【粘贴背景信息】
```

## 6. 进度与材料管理

### 6.1 生成时间线倒排
```
我计划【2027 秋】入学，目标地区【】。请按倒推方式给一份申请时间线：
语言考试、选校确定、文书初稿与定稿、CV、推荐信沟通、网申递交、面试、补材料、换无条件offer、签证，
各阶段的建议起止时间和里程碑；标注哪些项目是滚动录取要尽早交。
```

### 6.2 材料清单核对
```
根据我要申的这些项目，帮我汇总一份通用材料清单和各校差异项：
成绩单/在读证明、语言成绩、CV、PS、推荐信数量、GMAT/GRE、作品集、存款证明、护照等；
哪些需要公证/认证/翻译，哪些有格式或截止要求。
【粘贴项目列表】
```

### 6.3 每周复盘
```
这是我目前各项目的申请进度表。请帮我：
1. 标出临近 deadline 和卡住未完成的事项；
2. 指出下一步优先级；
3. 有没有遗漏的材料或风险点。

【粘贴进度表】
```
