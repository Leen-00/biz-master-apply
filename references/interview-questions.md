# 商科硕士面试题库与回答框架

> 用于 3.5 面试准备。回答遵循"具体事例 + 我的行动 + 结果反思"，避免空泛表态。

## 一、行为面（Behavioral）

### 1. 为什么选择这个项目 / 这个方向？
- 框架：兴趣起源（具体经历）→ 相关积累 → 项目如何接上我的目标 → 长期规划。
- 避免：只说学校排名高、地点好；要落到课程与经历契合。

### 2. 你的职业规划是什么？
- 框架：短期岗位/行业 → 中期想积累什么能力 → 长期方向；说明项目在路径中的位置。
- 注意：规划要与申请方向一致，不要前后矛盾。

### 3. 介绍一段你最有成就感 / 最困难的经历
- 框架：情境（Situation）→ 任务（Task）→ 行动（Action，突出我的贡献）→ 结果（Result）→ 反思（Reflection）。
- 准备 2-3 个可复用的故事：一个团队协作、一个解决难题、一个跨专业/抗压。

### 4. 团队合作中遇到分歧怎么办？
- 框架：分歧点 → 我怎么沟通与协调 → 最终方案 → 结果与学到的东西。

### 5. 你的优缺点是什么？
- 优点：配事例证明，不空谈。
- 缺点：说真实但不致命的短板 + 已采取的改进措施，不要说"我追求完美"这类套话。

### 6. 为什么跨专业申请？
- 框架：原专业给的基础 → 转向新方向的契机与准备 → 已补的先修课/作品/技能 → 新方向与长期目标的衔接。

## 二、专业 / 量化面（按方向准备）

### 金融方向常见
- 财务报表基础：三大表勾稽关系、关键比率（盈利能力、偿债能力、营运能力）。
- 公司金融：资本结构、折现、NPV、基本估值思路。
- 投资基础：风险收益、资产组合、常见金融工具概念。

### 会计方向常见
- 会计恒等式、权责发生制、收入确认、主要科目逻辑。
- 审计基本流程、内控概念（结合审计实习经历准备追问）。

### 商业分析 BA 方向常见
- 统计基础：均值/方差、分布、相关与回归、假设检验概念。
- 数据工具：SQL 基本查询、Python 数据处理、描述性分析思路。
- 案例：给一个业务问题，说清你会怎么取数、分析、给建议。

### 通用追问
- 解释你简历上某段实习具体做了什么、用了什么数据、结论是什么。
- 你在项目里最大的贡献是什么，团队其他人做了什么。

## 三、面试准备清单
- [ ] 简历每段经历都能讲出背景、行动、结果、反思
- [ ] 准备好 1 分钟与 3 分钟两个版本的自我介绍
- [ ] 了解目标项目的课程、方向、近期动态（官网核对）
- [ ] 准备 2-3 个反问面试官的问题（课程资源、就业支持、学生活动）
- [ ] 用 AI 模拟面试反复练，重点练临场组织语言与应对追问

## 四、回答原则
- 先给结论，再展开事例。
- 数字与经历必须真实，被追问时能自洽。
- 不会的问题：诚实说明了解程度，讲清思路，不要硬编。
- 语气自然直接，避免背诵模板感。
